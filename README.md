## IEPL 跨境专线到底是什么

IEPL 全称 International Ethernet Private Line，国际以太网专线。它是一条端到端的以太网电路，数据在运营商专门划分的网络里传输，不经过公网，所以不会被公网路由波动和拥塞影响。和传统 IPLC（International Private Leased Circuit）相比，两者本质都是点对点专线，主要差别在接口标准：IPLC 用的是传统 PDH/SDH 接口，IEPL 用以太网接口，可以做到 MAC 地址级别的电路配置，组网更灵活，通常也是目前更主流的交付形式。

用高速公路打比方的话：普通国际出口是所有人挤在同一条拥堵的公共高速上，IEPL 是一条封闭管理的专用车道，IPLC 则更接近完全点对点的直达通道。三者共同点是都走内网传输、不经过公网审查节点，延迟低且稳定。

Mkcloud 在售线路分三类，正好对应这三种技术形态：

| 线路类型 | 技术形态 | 特点 |
| --- | --- | --- |
| IEPL | 国际以太网专线 | 点对点专线，以太网接口，如广港线路 |
| IPLC | 国际专线电路 | 传统点对点专线，如沪日、沪港、沪美线路 |
| IX | 云厂内网接入 | 从云厂商内网进入专线网络，需搭配云厂 BGP 网络 |

三条路的入口不同、条件不同，这也是很多人选型时踩坑的地方，后面会展开。

## 什么人真的需要 IEPL 专线

先说清楚一件事：这类产品是云服务器，不是机场订阅。Mkcloud 的购买页写得很直白——所有产品均为云服务器/独立服务器，仅限个人或企业正规用途，禁止机场、回国等违法违规用途，发现即清退不退款。

它真正适合的场景很具体：

- **跨境电商运营**：在专线 VPS 里运行浏览器环境或管理工具，用干净的独立 IP 访问 Shopify、TikTok、亚马逊等平台后台，IP 质量稳定，不容易触发风控。
- **海外业务访问与管理**：社媒账号运营、海外广告投放管理、海外服务器运维，都需要一个稳定不掉线的网络出口。
- **持续数据传输**：备份、素材同步、跨海业务系统对接，独享带宽款保证持续速率。
- **对延迟敏感的华南—香港业务**：广港 IEPL 的端内延迟只有 1~2ms，广州到香港物理距离本来就近，走专线后基本等于没延迟。

如果你的需求只是偶尔看看网页，一个普通 VPS 或代理就够了，没必要花专线这个钱。专线解决的是「稳定、干净、持续」这三个普通产品给不了的问题。

## 常见问题

**IEPL 和 IPLC 选哪个？**
功能上都是点对点专线，IEPL 接口更新、组网更灵活，IPLC 更传统。对使用者来说差别不大，更重要的是选对方向和入口——广港还是沪港、香港出口还是日本出口，这比纠结两个缩写有意义得多。

**能不能用来搭机场或给国内翻墙？**
不能。Mkcloud 明确禁止机场、回国等用途，采用省级白名单加实名认证来落实，违规清退不退款。

**买错了省份或线路能换吗？**
省份白名单可以修改，但开通后不支持更换到其他地域的产品，退款仅限质量问题且需要提供数据证明。下单前把方向和接入条件确认好，是唯一的省钱方式。

**共享套餐的 200Mbps 是持续速度吗？**
不是，是峰值。持续跑大流量任务应该看独享带宽档位，或者按双向流量统计来估算用量。

**没有国内实名信息能用吗？**
不能用，实名是硬性要求，产品本身也需要遵守中国法律。
